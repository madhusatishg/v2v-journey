# 🧪 EXPERIMENT 4: Supervised ML Model

## 🎯 Goal

## ⚙️ Input Features

* distance
* speed
* signal state
* queue length

## 🎯 Output

* 0 → Do nothing
* 1 → Switch signal

## 🧠 Activities

1. Load dataset using pandas
2. Split into train/test
3. Train models:

4. Evaluate accuracy

## 📊 Metrics

* Accuracy
* Precision/Recall

## ✅ Success Criteria
